Programming/Coding Guidelines:

- The Project should be a Angular 22 Static Site Genration with Prerender Mode.
- You can Use opensource npm package, popular one with Public and anyone can use license.
- The Output generated by the Angular Prerendered Mode will be pushed directly to the Github Pages and will be server from there.
- Use Proper Component and Page Structure Wherever Needed.
- Use Proper SOLID Principal and Resusable component and framework wherever needed.
- Store Required Dynamic data for the page in separate JSON in Data folder organized by proper language/framework, Module and topic.
- The Code snippets Example should be there for each theoretical and practical aspect wherver possible.
- Add TypeCheck, Unit test and lint check from the begining of the project.
- Whenever you end with writing code perform typecheck, lint and unit-test check.
- During Implementation Planning and coding Review the Component structure and every module and reuse or create new component in such a way that generic naming convention and function name is used which can later on be reused.
- Use Proper Interface and Design Pattern wherever required for the extendability of the application.
